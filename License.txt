## 🔄 Pattern to Continue (Same Approach)

Every remaining page follows the **same three-file pattern** I've established:

1. HTML page with `<aside id="app-sidebar">`, `<header id="app-header">`, and `<div id="mobile-nav-mount">` + `<aside id="mobile-menu-mount">`
2. Include the shared script stack: `data/*.js` → `main.js` → `validation.js` → `auth.js` → `navigation.js` → (page-specific .js)
3. Call `initAppShell('student')` or `initAppShell('admin')` on DOMContentLoaded

The remaining ~75 pages (academics sub-pages, community, complaints, admin workspace, super-admin, system pages) all use this identical skeleton — they just swap in different content in the `<main id="main">` element and add their own page-specific JS file (e.g. `community.js`, `complaints.js`, `admin.js`, `leaders.js`, `search.js`, `emergency.js`).
