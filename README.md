# Campus Space

**Campus Space** is the student digital ecosystem for **Olusegun Agagu University of Science and Technology (OAUSTECH)**. It brings academics, community, opportunities, events, marketplace access, complaints, and emergency response into one polished, responsive experience.

This is a **frontend-only V1** built with HTML5, CSS3, and vanilla JavaScript. All functionality that would normally require a backend is simulated on the client using JavaScript, mock data and `localStorage`.

---

## Purpose

Campus Space is designed as a serious digital product — not a traditional school website. It aims to be the student's central digital home within the university, and to feel comparable in polish to commercial SaaS products.

---

## Tech Stack

- **HTML5** — semantic markup
- **CSS3** — one single stylesheet (`css/style.css`) using CSS variables and a full design system
- **Vanilla JavaScript** — no frameworks, no build step
- **Font Awesome 6** — interface icons
- **Google Fonts** — Manrope (headings) + Inter (body/UI)
- **Favicon.io** — favicon package derived from the Campus Space brand icon

No backend, no build tools, no external dependencies beyond the CDN references in the `<head>` of each page.
