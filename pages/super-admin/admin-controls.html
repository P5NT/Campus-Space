Admin Controls

Super Admin-only system controls. Settings persist across reloads.

These controls are visible to Super Admin only. Changes are recorded in the audit trail and take effect immediately in the live product.

Access controls

Pause or resume student-facing features.

Allow new student registrations

Turn off to temporarily pause new account creation.

Community posts enabled

Turn off to place the community in read-only mode.

Complaints intake enabled

Turn off to pause new complaint submissions.

Announcements publishing enabled

Turn off to prevent new announcements from being published.

Opportunities publishing enabled

Turn off to pause new opportunity listings.

System mode

Put the platform into restricted or maintenance states.

Maintenance mode

Show students a maintenance page. Only Admins can access the platform while enabled.

Read-only mode

Students can browse but cannot post, submit complaints, or interact.

Danger zone

Sensitive actions. Read carefully before proceeding.

Clear all Admin overrides

Wipes every admin override stored on this device — created admins, deactivations, and edits. Demo seed data remains.
